# 🦆 CloutDuck Planner

Персональный Telegram-планировщик, объединяющий задачи, расписание университета, тренировки и другие события в одном месте.

CloutDuck Planner автоматически формирует план дня и недели, следит за изменениями расписания и напоминает о предстоящих событиях.

## ✨ Возможности

### 📅 План дня

Бот собирает в единый план:

- пары ОмГТУ;
- занятия ОмГУ;
- китайский язык;
- тренировки;
- личные задачи;
- учебные задачи;
- задачи студии.

Доступны:

- план на сегодня;
- план на завтра;
- текущая неделя;
- следующая неделя.

### 🎓 Расписание ОмГТУ

CloutDuck Planner получает актуальное расписание ОмГТУ и учитывает:

- группу;
- подгруппу;
- время занятий;
- номер пары;
- аудиторию;
- адрес корпуса.

Бот также проверяет изменения расписания и может уведомлять о них.

### 👨 Расписание брата

Отдельный раздел позволяет посмотреть:

- расписание брата на сегодня;
- расписание брата на неделю.

### 📂 Задачи

Задачи разделены на три основных списка:

- 👤 Личные
- 🎓 По учёбе
- 🎬 Студия

Для каждой задачи можно указать:

- название;
- подробное описание;
- дату;
- время.

Поддерживаются:

- создание задачи;
- просмотр;
- редактирование;
- выполнение;
- удаление.

Задачи автоматически распределяются по разделам:

- 🔥 Сегодня
- ➡️ Завтра
- ⚠️ Просроченные
- 📅 Предстоящие
- ✅ Выполненные

Для больших списков используется постраничный просмотр.

### 🏋️ Тренировки

Планировщик автоматически подбирает дни тренировок с учётом:

- расписания ОмГТУ;
- расписания ОмГУ;
- занятий китайским;
- общей загруженности недели;
- расстояния между тренировочными днями.

### 🔔 Автоматические уведомления

Бот использует APScheduler для фоновых задач.

В частности:

- утром проверяет расписание;
- отправляет план на сегодня;
- вечером повторно проверяет изменения;
- формирует план на завтра;
- напоминает о событиях заранее.

## 📁 Структура проекта

```text
cloutduck-planner/
├── bot.py
├── database.py
├── requirements.txt
├── Dockerfile
├── docker-compose.portainer.yml
├── services/
│   ├── day_plan.py
│   ├── omgtu.py
│   └── ...
└── data/
```

`bot.py` содержит Telegram-интерфейс и основные обработчики.

`database.py` отвечает за SQLite и работу с задачами.

`services/` содержит отдельные модули планировщика: расписание, формирование плана дня и другую бизнес-логику.

## 🚀 Локальный запуск

Клонировать репозиторий:

```bash
git clone https://github.com/CloutDuck29/cloutduck-planner.git
cd cloutduck-planner
```

Создать виртуальное окружение:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать `.env`:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
TIMEZONE=Asia/Omsk
```

Запустить:

```bash
python bot.py
```

> Одновременно нельзя запускать две копии бота с одним Telegram Bot Token через long polling.

## 🐳 Docker

Проект собирается в Docker-образ и публикуется через GitHub Actions:

```text
ghcr.io/cloutduck29/cloutduck-planner:latest
```

Для production используется persistent volume для базы данных:

```text
/app/data/planner.db
```

Поэтому данные SQLite сохраняются при обновлении контейнера.

## ⚙️ Конфигурация

Основные переменные окружения:

```env
BOT_TOKEN=
TIMEZONE=Asia/Omsk
OMGTU_GROUP=АТП-261
DATABASE_PATH=/app/data/planner.db
```

Секреты и локальная база данных не должны попадать в Git.

## 🔄 Deployment

Схема обновления проекта:

```text
Изменения кода
      ↓
GitHub
      ↓
GitHub Actions
      ↓
Docker image
      ↓
GHCR
      ↓
Portainer
      ↓
CloutDuck Planner
```

После push в `main` GitHub Actions собирает актуальный Docker-образ, который затем используется серверным контейнером.

## 🦆 CloutDuck

CloutDuck Planner создаётся как персональная система планирования, а не универсальный todo-бот.

Главная идея проекта — собрать расписание, обязательства и задачи из разных частей жизни в один автоматически формируемый план.
